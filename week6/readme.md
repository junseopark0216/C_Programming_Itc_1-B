정렬 알고리즘 3종 정리
선택 정렬 (Selection Sort)

개념: 전체에서 가장 작은 값을 찾아서 맨 앞과 교체. 그 다음 작은 값 찾아서 두 번째와 교체. 반복.

[64, 25, 12, 22, 11]
 ↑ 여기에 최솟값 11 가져옴 → [11, 25, 12, 22, 64]
     ↑ 여기에 최솟값 12 가져옴 → [11, 12, 25, 22, 64]

시간복잡도: O(n²)
교환 횟수가 적음 (최대 n-1번)

버블 정렬 (Bubble Sort)

개념: 인접한 두 값을 비교해서 크면 뒤로 보냄. 한 바퀴 돌면 가장 큰 값이 맨 뒤로 감. 반복.

[5, 3, 1, 4]
 5>3 → 교체: [3, 5, 1, 4]
    5>1 → 교체: [3, 1, 5, 4]
       5>4 → 교체: [3, 1, 4, 5] ← 5가 맨 뒤로 버블처럼 올라감

시간복잡도: O(n²)
구현 제일 단순하지만 교환 횟수 많음
삽입 정렬 (Insertion Sort)

개념: 카드 정렬하듯이, 새 카드를 이미 정렬된 패에 올바른 위치에 끼워 넣음.

[5, 3, 1, 4]
[5] → 3 삽입 → [3, 5]
[3, 5] → 1 삽입 → [1, 3, 5]
[1, 3, 5] → 4 삽입 → [1, 3, 4, 5]

시간복잡도: O(n²), 거의 정렬된 데이터엔 O(n)
실제로 소규모 데이터에서 가장 빠름
