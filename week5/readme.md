## 배열 (Array)

### 변수 vs 배열

- `int a` : 메모리 안에 `a`라는 값 하나가 위치
- `int a[10]` : 메모리의 **시작 주소**를 `a`로 지정, 연속된 공간에 10개의 값 저장

배열은 메모리의 **연속적인 공간**에 저장되며, 저장된 각 데이터를 **요소(element)** 라고 한다.

### 배열 선언과 초기화

c

```c
int a[] = {1, 2, 3};  // 초기화된 경우 → 크기 생략 가능int a[10];            // 초기화 안된 경우 → 크기 지정 필수
```

- 초기화 시 남는 공간은 **0으로 자동 채워짐**

c

```c
int arr[5] = {1, 2};  // → {1, 2, 0, 0, 0}
```

### 배열과 주소

- 배열명 `a`는 배열의 **시작 주소**를 의미
- 64비트 환경에서 포인터(주소)는 **8바이트**

### 배열을 함수에 전달할 때

- 배열명을 매개변수로 넘기면 **배열 전체를 복사하지 않고 시작 주소만 전달**
- 시작 주소만 알면 연속된 메모리를 순서대로 접근할 수 있기 때문

c

```c
void func(int arr[], int size) { ... }int main() {    int a[5] = {1, 2, 3, 4, 5};    func(a, 5);  // a = 시작 주소만 전달}
```
