srand(time(NULL)):하는 이유는, rand 함수는 난수를 주지만 이는 일정 배열에서 제공되는 것이라, 무조건적인 난수가 아니기 때문이다.
이를 난수로 만들기 위해 컴퓨터 시간을 기반으로 난수를 생성하면, 진정한 난수처럼 만들 수 있다.

전역변수를 최소화하는 코딩이 좋은 코딩이다.
전역변수를 남용하면 변수의 사용 범위와 캡슐화를 깨뜨릴 위험이 있기 때문이다.

전역변수와 지역변수명이 동일 할 때, 그 지역 스코프에 있는 지역변수가 우선시된다.
전역변수는 자동으로 초기화된다.

가변 매개변수 사용 시, 정해진 건 앞에 쓰고 가변변수는 뒤에 써야한다.
가변 매개변수를 사용하면, 매개변수의 갯수를 따로 정하지 않고 유연하게 사용이 가능하다.
